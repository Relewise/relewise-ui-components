Universal Search

This page exercises the universal-search modal with the Universal Search clothing demo dataset.

  • Products, product categories, and content tabs are configured with page size 15.
  • Product facets: brand, category, price, color, material, fit, season, and on-sale state.
  • Product category facets: gender, age group, department, season, and category type.
  • Content facets: content category, article type, topic, audience, season, and featured state.
  • Product sorting: relevance, price, name, brand, popularity, and demo product data score.
  • Product, product category, and content rendering use template overrides to show seeded images, URLs, descriptions, and metadata.
  • Images are requested from the seeded ImageUrl data key.
  • Load more URL state uses entity-scoped take parameters.
  • Enabled tabs are searched together in a batched search request.
  • Facet and sorting changes search only the active tab.
