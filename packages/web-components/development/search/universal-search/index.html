Universal Search

This page exercises the universal-search modal and the currently implemented result tabs.

  • Products, product categories, and content tabs are configured with page size 15.
  • Product facets: brand, immediate parent category, and sales price.
  • Content facets: immediate parent category, with a commented custom data-key facet example in index.ts.
  • Product category facets can be configured with product category data keys; see the commented example in index.ts.
  • Product sorting: relevance, price, name, brand, and popularity.
  • Product rendering through relewise-product-tile with a demo templates.product override.
  • Product category rendering through relewise-category-tile with templates.productCategory support.
  • Content rendering through relewise-content-tile.
  • Product images requested from Image, with ImageUrl as fallback.
  • Load more URL state uses entity-scoped take parameters.
  • Enabled tabs are searched together in a batched search request.
  • Facet and sorting changes search only the active tab.
